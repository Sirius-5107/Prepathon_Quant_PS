READY FOR TASK 2
================================================================================

The framework is ready to accept new strategies. To add a new strategy:

1. Create file: strategies/alpha_01_mean_reversion.py

   from strategy import BaseStrategy
   
   class MeanReversionStrategy(BaseStrategy):
       def __init__(self):
           super().__init__("Mean Reversion")
           self.metadata = {
               'hypothesis': 'Overbought/oversold conditions mean-revert',
               'signals_used': ['BB03', 'BB04', 'PB07'],
           }
       
       def generate_signal(self, data):
           latest = data.iloc[-1]
           if latest['BB03'] == 1:  # Overbought
               return -1  # Short signal
           return 0

2. Run it:

   from backtester import Backtester
   from strategies.alpha_01_mean_reversion import MeanReversionStrategy
   
   strategy = MeanReversionStrategy()
   backtester = Backtester()
   results = backtester.run(price, signals, strategy)
   print(results['performance'])

3. Analyze:
   - Check Sharpe ratio
   - Test robustness (different periods, costs, parameters)
   - Validate hypothesis with statistical tests

================================================================================
KEY DESIGN DECISIONS
================================================================================

✓ Modular architecture: Each component independent & testable
✓ Timing convention: Strictly enforced (t-1 → t open)
✓ Mandatory costs: 0.05% per side, not parameterized
✓ Lookahead prevention: Chronological, no future data
✓ Forward returns: Used only as labels, never as signal inputs
✓ Trade logging: Every trade recorded with cost
✓ Reproducibility: Same code + data = same results
✓ Extensibility: New strategies plug in without rewriting core

================================================================================
PERFORMANCE METRICS CALCULATED
================================================================================

For each strategy backtest, you get:
  - Total return (%)
  - Annualized return (%)
  - Volatility (%)
  - Sharpe ratio (vs 2% risk-free)
  - Sortino ratio (downside volatility)
  - Maximum drawdown (%)
  - Drawdown duration (days)
  - Calmar ratio (return / max drawdown)
  - Trade statistics (count, etc.)

All calculated and saved to JSON for downstream analysis.
