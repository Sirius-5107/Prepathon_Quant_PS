### Required modules

- `quant_project/final_evaluation.py` — reports train/validation/test and null-baseline diagnostics.
- `quant_project/task3_backtest.py` — orchestration and output generation.

### Evaluation design and caveats

- Rolling portfolio-construction schedule: 504 observations for training, internal 80/20 train/validation split, refit on all 504 observations, then 63 observations OOS.
- The Task 3 schedule has **8 rolling OOS blocks**; this is separate from the **7 Task 2 alpha-selection WFO folds**.
- Learned component: one trailing mean/volatility score per selected strategy; low capacity relative to the short sample.
- Turnover cost: 0.05% per unit turnover, charged on the first day of each OOS rebalance block. The first block starts from equal weights; moving to the first target produces 1.3333 turnover.
- Factor diagnostic uses the equal-weight selected-strategy basket as an **endogenous** factor; it is not external market-factor attribution.
- The first four allocator comparison rows (best individual, equal-weight, ERC, maximum Sharpe) are full-sample descriptive baselines. Only the proposed dynamic row is stitched OOS. The maximum-Sharpe row must not be presented as OOS performance.
- ERC was corrected to minimize dispersion in log component risk contributions under long-only, sum-to-one weights; it no longer collapses to equal weights.

### Reported learned-component diagnostics

|---|---:|---:|
| Train | 20.54% | 1.592 |
| Validation | 7.12% | 1.843 |
| OOS test blocks | 4.09% | 1.758 |

Stitched dynamic OOS results: cumulative return **35.26%**, CAGR **17.10%**, annual volatility **6.70%**, Sharpe **2.390**, maximum drawdown **-2.17%**. These figures are specific to the stored run and must be interpreted alongside the fold-level results and null comparison, not in isolation.

Permutation null (500 repetitions): observed OOS total return **35.26%**; null mean **24.86%**; null standard deviation **7.47%**; null 95th percentile **37.70%**; 56/500 null runs reached or exceeded the observed result (**11.2%**). This is a diagnostic exceedance rate, **not** a formal p-value or a claim of statistical significance. The observed result does not exceed the null's 95th percentile.
