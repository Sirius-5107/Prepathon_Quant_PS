HOW TO USE
================================================================================

1. CLONE THE REPO:
   git clone https://github.com/Sirius-5107/Prepathon_Quant_PS.git
   cd Prepathon_Quant_PS

2. RUN THE FRAMEWORK:
   cd quant_project
   python main.py
   
   Expected output: All metrics computed, results saved

3. REVIEW RESULTS:
   cat baseline_performance.json
   # Shows: Total return 1.83%, Sharpe -0.42, Max DD -2.08%

4. BUILD NEW STRATEGIES:
   Create: quant_project/strategies/alpha_01_your_strategy.py
   Run backtest and review results

5. READ DOCUMENTATION:
   Start with: README.md → QUICK_START.txt → IMPLEMENTATION_NOTE.md
